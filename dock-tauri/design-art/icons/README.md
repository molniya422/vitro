# 应用图标 v1

由 `tools/export-icons.py` 导出。48 及以上用 `art/mark.svg`，32 及以下用 `art/mark-small.svg`。

| 文件 | 尺寸 | 典型用途 |
|---|---|---|
| `icon-512.png` | 512 | 商店页、安装器、关于页 |
| `icon-256.png` | 256 | 大图标视图、.ico 最大档 |
| `icon-128.png` | 128 | Win10 磁贴、高清屏 |
| `icon-64.png` | 64 | 中等图标 |
| `icon-48.png` | 48 | 标准应用图标 |
| `icon-32.png` | 32 | 任务栏、Alt-Tab |
| `icon-24.png` | 24 | 小图标视图 |
| `icon-16.png` | 16 | 标题栏、托盘 |
| `dock.ico` | 16 到 256 | exe、快捷方式、安装包 |
| `preview.png` | 1240 x 648 | 尺寸对照，深色与浅色两带 |

## 尺寸策略

- 48 及以上保留完整标记：玻璃架、三枚静置磁贴、一枚抬升磁贴。
- 32 及以下换成简化标记，删掉三枚静置磁贴，否则 16 px 下会糊成一团。
- 48 及以上留 4% 透明边；32 及以下满出血，把有限的像素都留给图形。

## 重新导出

```
python tools/export-icons.py
```

脚本用无头浏览器渲染（透明底），Pillow 裁剪到实际绘制区域再缩放，因此不受浏览器窗口边框影响。
`dock.ico` 用 PNG 负载打包，Windows Vista 及以上原生支持。

## 注意

- 不要手动修改导出的 PNG，改 `art/mark*.svg` 后重新跑脚本。
- `.ico` 里 16、24、32 三档来自简化标记，48 以上来自完整标记，混用会看出风格突变。
- 图标没有文字，任何语言下都成立。
