# Dock 视觉资产规范 v1

> 范围：只定义视觉资产与美术规范。不含技术选型、组件结构、交互状态机与代码。
> 落地资产：`tokens/` 与 `art/`，本文件是它们的验收依据。

---

## 假设

1. 产品是 Windows 10/11 桌面 Dock，默认底部停靠，最多 10 个槽位。
2. 应用图标由系统 Shell 提取，风格不可控，所以底座必须中性、透明、不抢色。
3. 默认图标 48 逻辑像素，可调 32 到 80。
4. 深色是默认主题，浅色是同级主题，不是附属品。
5. 壁纸不可预知，每套材质都必须有对比度下限（见「材质与模糊」）。
6. 主题包只换视觉令牌与贴图，不换行为。
7. 发布包不含任何第三方图标素材，字形全部自绘。
8. 资产以 SVG 与令牌为主；位图只用于特效、托盘、安装器、商店预览。

---

## 视觉方向摘要

一句话：**冷调玻璃架，状态写在图标本体上。**

四条不可动摇的规则：

1. 材质表达层级，描边不表达层级。
2. 全库 1 个强调色，1 条冷灰阶，1 个形状家族。
3. 光影只做内侧：1 px 内高光加内阴影，没有外发光。
4. 状态画在图标本体上，不新增容器。

三个贯穿全库的数字：**48**（图标基准）、**1.6**（放大峰值）、**22.37%**（超椭圆等效圆角）。

色彩基调：冷调 slate，深端 `#0f131c`，浅端 `#f4f6fb`，强调色 `#7c9be0`（221 度，饱和 62%）。语义色 `#6fa896` / `#d9a45c` / `#d46a62` 只用于阈值与角标。

## 风格方案

三套全部随包发布，用户可自由切换。切换只换视觉令牌，不换图标形状、字形、放大曲线与状态语义。3 种风格与深浅主题可自由组合，共 6 种外观。

### A 冷调玻璃（默认，推荐）

| 项 | 参数 |
|---|---|
| 适用 | 深色壁纸、长时间驻留、想要 macOS 邻近感但不照搬 |
| 底板 | `#161a26` @ 62% |
| 文字 / 弱化 | `#e9edf7` / `#98a1b6` |
| 强调 | `#7c9be0` |
| 材质 | 填充 62%，顶部高光 15%，底部内阴影 15%，颗粒 0.25%，模糊 0 |
| 光影 | 内高光 1 px 白 15%，内阴影 1 px 黑 15%，底部环境影 `inset 0 -10px 18px` 黑 8%，图标投影 `0 3px 5px` 黑 35% |
| 圆角 | 药丸 = 高度 / 2（48 图标时为 34），图标 22.37%，面板 18，菜单 10，条目 6 |
| 间距 | 图标间距 8，内边距 16 / 10，分隔线 1 × 72% 图标高 |

这是默认包。所有其他风格以它为零点做加减。

### B 裸排版（无底板）

| 项 | 参数 |
|---|---|
| 适用 | 极简壁纸、低配机、喜欢「图标直接贴在桌面上」的用户 |
| 底板 | 无填充，或最多 18% 中性色 |
| 材质 | 无玻璃、无颗粒、无倒影 |
| 光影 | 图标各自 `0 2px 6px` 黑 30%，不共享底板投影 |
| 圆角 | 图标仍是 22.37%，但移除药丸，整条 Dock 无外框 |
| 间距 | 图标间距 12，上下留白 8 / 6，比 A 更松 |
| 可读性 | 浅壁纸上必须给图标加 1 px 反色描边（白 28%），否则边缘糊掉 |

随包提供但非默认。浅色壁纸下自动加 1 px 反色光环，不给用户第二个开关。

### C 磨砂亚克力

| 项 | 参数 |
|---|---|
| 适用 | Windows 11、独显、想要真实桌面模糊 |
| 底板 | 深色 黑 25%，浅色 白 18% |
| 材质 | 模糊 22 / 20，饱和 1.08 / 1.04，颗粒 0.25% / 0.30%，顶部高光 15% / 30%，底部内阴影 15% / 10% |
| 光影 | 额外 1 px 外描边 白 8%（深）/ 黑 8%（浅），在花壁纸上勾边 |
| 圆角 | 同 A |
| 硬约束 | 模糊区域必须裁成药丸形状，否则会把图标上方的留白一起糊掉，比不做更脏 |

### 不推荐：暗黑霓虹

霓虹描边加高频发光在长时间驻留下会疲劳；Windows 桌面壁纸偏亮，霓虹边在高亮区会直接消失；与「精致」目标冲突。若要做，限定为独立的「游戏模式」主题包，不进默认包。

### 三套对比

| 维度 | A 冷调玻璃 | B 裸排版 | C 亚克力 |
|---|---|---|---|
| 壁纸容错 | 高 | 低 | 中（花壁纸最好） |
| 低配友好 | 高 | 最高 | 低 |
| 与 macOS 距离 | 近 | 远 | 最近 |
| 实现成本 | 低 | 低 | 高 |

### 切换规则

1. 三套共享同一套图标遮罩、字形、运行点与放大曲线。
2. 只有这些令牌允许随风格变化：底板填充、模糊、颗粒、倒影、外缘光环、图标投影、间距与内边距。
3. 切换会改变窗口几何：B 的间距 12 与内边距 12 / 8 比 A 更松，药丸尺寸与放大中心必须重算。
4. C 的模糊必须裁成药丸；裁不出来就降级为 A，不要退化成矩形毛玻璃。
5. 风格与深浅主题正交，任何组合都必须通过对比度下限检查。
6. 默认 A。首次启动不弹风格选择，设置页提供「Glass / Bare / Frost」三选一。

## 图标状态规范

### 底座规则

- 容器严格等于图标，不加内边距。来源图标自带留白，再加会缩小可视尺寸。
- 任何来源的图标都强制套用 22.37% 超椭圆遮罩，保证同一排的轮廓一致。
- 投影 `0 3px 5px` 黑 35%，只允许一档。不要因为图标多就加深。
- 内高光 1 px 白 12% 贴着遮罩内缘，让深色图标在深色底板上仍有轮廓。
- 应用图标不加描边。描边只属于线性系统字形。
- 系统字形 24 网格，描边 1.7，圆头，圆角连接。
- 安全区 6%：来源图标的最外一像素不参与信息表达，允许被遮罩切掉。

### 状态表

| 状态 | 缩放 | 位移 | 不透明度 | 亮度 | 饱和 | 附加 |
|---|---|---|---|---|---|---|
| 默认 | 1.00 | 0 | 100% | 100% | 100% | 运行则带点 |
| 悬停 | 按放大曲线 | 0 | 100% | 103% | 100% | 500 ms 后出气泡 |
| 按下 | 0.90（仅图像层） | 0 | 96% | 92% | 100% | 投影缩短为 `0 1px 2px` |
| 运行 | 1.00 | 0 | 100% | 100% | 100% | 4 px 运行点 |
| 通知 | 1.00 | 0 | 100% | 100% | 100% | 角标弹入 |
| 禁用 | 1.00 | 0 | 70% | 100% | 0% | 无运行点 |
| 拖拽 | 1.08 | -4 px | 88% | 104% | 100% | 旋转 -1.5 度，投影 `0 12px 28px` 黑 46% |
| 投放位 | 1.00 | 0 | 100% | 100% | 100% | 虚线槽 |

禁止：给悬停态加背景块、加描边、改图标色相；给运行态换彩色图标；把禁用做成隐藏。

### 放大联动

`transform-origin` 固定在底边中心，图标向上生长，底边不动。

| 距离（图标格） | 倍率 | 观感 |
|---|---|---|
| 0.0 | 1.600 | 指针所在 |
| 0.5 | 1.562 | 仍在峰顶 |
| 1.0 | 1.212 | 邻接抬升 |
| 1.5 | 1.003 | 几乎归位 |
| 2.2 | 1.000 | 完全静止 |

峰值 1.6 时，视觉上只有左右各 1 个图标会明显动。想让联动更宽，改作用半径，不要改峰形。

## 材质与模糊

### 深色

| 层 | 参数 |
|---|---|
| 填充 | `#161a26` @ 62% |
| 模糊 | 0（绘制玻璃）或 22 px（亚克力） |
| 饱和 | 1.00 / 1.08 |
| 颗粒 | 0.25%，64 px 平铺，去饱和噪点 |
| 顶部高光 | 1 px 白 15% |
| 底部内阴影 | 1 px 黑 15% |
| 底部环境影 | `inset 0 -10px 18px` 黑 8% |

### 浅色

| 层 | 参数 |
|---|---|
| 填充 | `#f7f9fd` @ 72% |
| 模糊 | 0 或 20 px |
| 饱和 | 1.00 / 1.04 |
| 颗粒 | 0.30% |
| 顶部高光 | 1 px 白 90% |
| 底部内阴影 | 1 px 黑 10% |
| 运行点 | 黑 45% + 1 px 白环 55% |

浅色下运行点必须换色加环，否则 4 px 白点在白壁纸上等于不存在。分隔线同理，改用黑 14%。

### 可读性下限

壁纸不可知，按合成亮度分档：

- L 小于 0.35：白字 100%。
- L 在 0.35 到 0.6：白字加 1 px 柔影，黑 40%，纵向偏移 1。
- L 大于 0.6：深字 `#20242e`，弱化 `rgba(32,36,46,.66)`。

亚克力档额外要求：填充透明度不低于 18%，模糊不低于 20 px。低于这两个值，白壁纸上的文字对比会崩。

### 噪点规则

- 只用 64 px 平铺的灰噪点，透明度 0.25% 到 0.30%。
- 只贴在底板的伪元素上，不贴滚动容器，不贴每帧重绘的图层。
- 噪点不能用位图整块拉伸，会糊成脏斑。

### 不做

- 不加外描边表达层级（亚克力的 8% 勾边是唯一例外，用于花壁纸）。
- 不加外发光（默认关闭，上限 8% 强调色）。
- 不用纯黑 `#000000`，最深到 `#0f131c`。
- 不让设置页透明。

## 动效视觉

只描述观感参数，不写实现。

| 动作 | 视觉变化 | 时长 | 缓动 |
|---|---|---|---|
| 悬停放大 | 图标向上生长，底边不动，邻接递减 | 跟随 160 ms | `cubic-bezier(.22,1,.36,1)` |
| 离开复位 | 回落并轻微过冲 | 320 ms | `cubic-bezier(.34,1.36,.64,1)`，过冲不超过 3% |
| 按下 | 图标内容缩到 0.90，亮度降到 92% | 90 ms | 同跟随曲线 |
| 松开 | 弹回 1.00 | 120 ms | 弹簧 |
| 启动弹跳 | 向上 34 px 再落回，两次后止 | 600 ms | 弹簧 |
| 提示气泡 | 淡入并上移 6 px | 150 ms | 同跟随曲线 |
| 气泡消失 | 纯淡出 | 50 ms | 线性 |
| 菜单弹出 | 淡入、从 0.97 放大到 1、下移 2 px 归位 | 250 ms | 同跟随曲线 |
| 菜单关闭 | 纯淡出 | 150 ms | 同跟随曲线 |
| 角标 | 从 0.4 弹到 1，带轻微过冲 | 500 ms | 弹簧 |
| 拖拽抬起 | 放大 1.08，旋转 -1.5 度，上移 4 px，阴影变长 | 160 ms | 同跟随曲线 |
| 拖拽落定 | 回正 | 320 ms | 弹簧 |
| 邻居让位 | 水平位移一个栅格 | 200 ms | 同跟随曲线 |
| 拖出移除 | 淡出并缩到 0.86 | 160 ms | 加速曲线 |
| 自动隐藏 | 整体平移出屏，同步淡出 | 200 ms | 缓出 |
| 设置即时预览 | 参数变化直接生效，不加过渡 | 0 ms | 无 |

节奏原则：

1. 进入要跟手，退出要有重量。所以进入 160 ms，退出 320 ms 且带回弹。
2. 放大是一条平滑的透镜波，不是每个图标各弹一下。
3. 同一时刻只允许一个图标处于「按下」或「拖拽」。
4. 减少动效模式下，放大关闭，其余全部退化为淡入淡出。

## 主题包清单

随包发布三套：`themes/cool-glass/`、`themes/bare/`、`themes/frost/`，各自带 `theme.json` 与说明。

一套主题是一个目录，只换视觉，不换行为。

```
themes/<id>/
  theme.json                 颜色、形状、材质、动效令牌
  README.md                  说明与文件清单
  preview.png                1280 x 800 深色预览
  preview-light.png          1280 x 800 浅色预览
  dock/                      仅本风格特有：plate-*.svg 或 halo-*.svg
```

共享部件不复制进每个主题：

| 目录 | 内容 |
|---|---|
| `art/dock/` | 分隔线、运行点（深/浅）、角标、投放槽（空/激活）、倒影遮罩 |
| `art/overlay/` | 提示气泡（深/浅）、菜单底板（深/浅）+ 九宫格参数 |
| `art/fx/` | 颗粒 64 px 平铺图 |
| `art/` | 37 枚字形、超椭圆、插件磁贴、品牌标记 |

`theme.json` 最少字段：

```json
{
  "id": "cool-glass",
  "name": "Cool Glass",
  "author": "dock",
  "appearance": "dark",
  "color": {
    "plate": "#161a26",
    "plateAlpha": 0.62,
    "text": "#e9edf7",
    "muted": "#98a1b6",
    "accent": "#7c9be0",
    "badgeTop": "#e2605a",
    "badgeBottom": "#c8433d"
  },
  "shape": { "iconRadius": 0.2237, "pillRadius": "half", "panelRadius": 18, "menuRadius": 10 },
  "material": { "blur": 0, "saturate": 1, "grain": 0.0025, "topHighlight": 0.15, "bottomShadow": 0.15 },
  "motion": { "magnifyPeak": 1.6, "followMs": 160, "settleMs": 320 }
}
```

Lottie 只用于三种一次性特效：移除烟团、启动弹跳、注意力脉冲。其余全部用变换完成，因为 Lottie 会额外占用合成层。序列帧是 Lottie 不可用时的降级：16 帧，每帧 20 ms，`@2x` PNG，透明底。

## 切图交付规格

### 格式选择

| 格式 | 用在哪 | 不用在哪 |
|---|---|---|
| SVG | 底板、分隔线、字形、遮罩、角标、超椭圆 | 含复杂模糊或颗粒的成品 |
| PNG | 九宫格位图、托盘图标、安装器、特效帧 | 可矢量的形状 |
| WebP | 商店预览、主题缩略图 | 运行时 UI 贴图 |
| Lottie JSON | 烟团、弹跳、脉冲 | 常驻循环动画 |

### 单独打开时的预览底

组件 SVG 直接打开时必须能看见，否则交接时无法判断对错。因此每个组件文件都包含：

1. 一组 `id="preview-stage"` 的预览底：深色或中灰壁纸渐变，加一层品牌色微光。
2. 画布四周 12 到 40 单位的留白，资产不再铺满画布。
3. 显示尺寸放大到 125 到 560 px，`viewBox` 保持真实比例，几何不被改写。

接入时删除 `preview-stage` 整组，保留 `id="asset"`，即得到透明资产。
`currentColor` 类资产（分隔线、倒影遮罩）在文件内预设了浅色默认值，接入时由宿主覆盖。

不要用 `width`/`height` 判断资产尺寸，以 `viewBox` 为准。

### 倍率

- 矢量资产不提供倍率，一份源。
- 位图资产提供 `@1x` `@1.5x` `@2x`，分别对应 100% / 150% / 200% 缩放。
- 默认只切 1x 与 2x；1.5x 仅在 150% 缩放下出现明显模糊时才补。
- 内边距与圆角写逻辑像素，由系统缩放，不预先乘倍率。

### 命名

```
<模块>/<组件>[-<状态>][@<倍率>].<扩展名>
```

示例：

- `dock/plate-dark.svg`
- `dock/badge.svg`
- `overlay/menu-item-hover@2x.png`
- `dock/tile-state-dragging.png`
- `glyphs/g-trash-full.svg`

状态后缀固定 11 个：`default` `hover` `pressed` `running` `disabled` `notify` `dragging` `drop` `focus` `selected` `danger`。不用 `active`、`normal`、`on` 之类的别名。

深色与浅色用 `-dark` `-light` 后缀，不用目录区分，避免引用路径分裂。

### 九宫格

只有位图主题需要九宫格，规则：

- 切边 = 圆角像素值，四边相同。34 px 圆角就切 34。
- 中心区必须是纯渐变或纯色，不能含噪点，否则拉伸后会出现接缝。
- 四角不允许包含投影，投影单独一层叠加。
- 同名 `.9.json` 记录 `{ "left": 34, "right": 34, "top": 34, "bottom": 34 }`。

矢量的药丸不切九宫格，直接按高度 / 2 生成，能随图标尺寸变化。

### 出血与外扩

- 有投影的资产留 8 px 出血，四边各 8，避免导出时被裁。
- 1 px 描边对齐到像素中心，导出前检查是否落在半像素。
- 文字一律不进图，全部由运行时排版。

### 导出检查表

1. 画板尺寸是 4 的倍数。
2. 透明底，无白底残留。
3. 投影未被裁切。
4. 1 px 线在 100% 与 200% 下都清晰。
5. 深色与浅色两套都导出，且文件名只差后缀。
6. 每个状态都有对应文件，缺状态视为未完成。
7. 主题包根目录有 `theme.json` 与 `README.md`。
