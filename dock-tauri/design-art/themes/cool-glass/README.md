# Cool Glass

默认风格。绘制玻璃，零原生依赖，任何 Windows 版本观感一致。

- 底板 `#161a26` @ 62%，顶部高光 15%，颗粒 0.25%，倒影 25%
- 图标间距 8，内边距 16 / 10，药丸圆角 = 高度 / 2
- 适用：深色壁纸、长时间驻留

## 文件

| 文件 | 用途 |
|---|---|
| `dock/plate-dark.svg` | 四层药丸，图层命名 fill / sheen / ambient / edge |
| `dock/plate-light.svg` | 浅色版本，填充 72%，顶部高光 90% |
| `preview.png` | 1280 x 800 深色预览 |
| `preview-light.png` | 1280 x 800 浅色预览 |

共享部件（分隔线、运行点、角标、投放槽、倒影遮罩、菜单、提示气泡、颗粒）在 `../../art/`。
