# 主题包 v1

三套风格随包发布，用户可自由切换。切换只换视觉令牌，不换图标形状、字形、放大曲线与状态语义。

| 目录 | 风格 | 默认 | 材质 | 适用 |
|---|---|---|---|---|
| `cool-glass/` | A 冷调玻璃 | 是 | 绘制玻璃 | 深色壁纸、长时间驻留 |
| `bare/` | B 裸排版 | 否 | 无底板 | 极简壁纸、低配机 |
| `frost/` | C 磨砂亚克力 | 否 | 原生模糊 | Windows 11、独显、花壁纸 |

## 切换规则

1. 三套都必须保留：22.37% 超椭圆、24 / 1.7 字形、1.6 放大峰值、4 px 运行点。
2. 只有这些令牌允许随风格变化：底板填充、模糊、颗粒、倒影、外缘光环、图标投影、间距与内边距。
3. 切换风格会改变窗口几何（`bare` 更松），药丸尺寸与放大中心必须重算。
4. `bare` 在浅色壁纸上自动加 1 px 反色光环，不提供第二个开关。
5. `frost` 的模糊必须裁成药丸；做不到就降级为 `cool-glass`，不要退化成矩形毛玻璃。
6. 风格切换不等同于深浅主题切换，两者可自由组合：3 风格 × 2 主题 = 6 种外观。

## 文件约定

```
themes/<id>/
  theme.json          颜色、形状、材质、动效令牌
  README.md           说明与文件清单
  preview.png         1280 x 800 深色预览
  preview-light.png   1280 x 800 浅色预览
  dock/               只放本风格特有的底板或光环
```

共享部件不复制进每个主题，统一放在：

| 目录 | 内容 |
|---|---|
| `../art/dock/` | 分隔线、运行点、角标、投放槽、倒影遮罩 |
| `../art/overlay/` | 提示气泡、菜单底板与九宫格参数 |
| `../art/fx/` | 颗粒平铺图 |
| `../art/` | 字形、超椭圆、插件磁贴、品牌标记 |

组件 SVG 都带一层 `id="preview-stage"` 预览底，单独打开时可见。
接入时删掉这一组，保留 `id="asset"` 即为透明资产。

Lottie 特效（移除烟团、启动弹跳、注意力脉冲）暂未提供。这三种效果当前用变换实现；
只有在需要粒子或形变时再补 `fx/*.json`，否则不要为空目录占位。

## 重新出图

preview 由预览页直接导出，页面本身不画任何假截图：

```
preview/dock.html?chrome=off&style=<glass|bare|frost>&theme=<dark|light>
```

用无头浏览器按 1310 x 900 窗口截图，再把左上角裁到 1280 x 800。
本机窗口边框占 30 x 100，换机器先量一次再批量导出。
`chrome=off` 只隐藏工具条与提示，其余仍是真实渲染。
