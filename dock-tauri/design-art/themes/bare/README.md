# Bare

无底板风格。图标直接浮在壁纸上，靠自身投影与 1 单位反色光环区隔。

- 无填充、无颗粒、无倒影、无药丸
- 图标间距 12，内边距 12 / 8
- 浅色壁纸下光环自动转为深色，不给用户第二个开关
- 适用：极简壁纸、低配机

## 文件

| 文件 | 用途 |
|---|---|
| `dock/halo-dark.svg` | 深色壁纸用的 1 单位外光环 |
| `dock/halo-light.svg` | 浅色壁纸用的深色光环 |
| `preview.png` | 1280 x 800 深色预览 |
| `preview-light.png` | 1280 x 800 浅色预览 |

本风格没有底板文件，这是设计决定，不是缺件。
