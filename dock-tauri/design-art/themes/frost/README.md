# Frost

磨砂亚克力风格。真实桌面模糊，需要药丸形状的原生模糊区域。

- 深色 黑 25% + 模糊 22 + 饱和 1.08；浅色 白 18% + 模糊 20 + 饱和 1.04
- 额外 1 单位勾边，白 8%（深）/ 黑 8%（浅）
- 模糊区域裁不出药丸时自动降级为 `cool-glass`
- 适用：Windows 11、独显、花壁纸

## 文件

| 文件 | 用途 |
|---|---|
| `dock/plate-dark.svg` | 深色药丸，模糊由合成器施加，文件只负责填充与勾边 |
| `dock/plate-light.svg` | 浅色药丸，填充 18% 是下限 |
| `preview.png` | 1280 x 800 深色预览 |
| `preview-light.png` | 1280 x 800 浅色预览 |

共享部件在 `../../art/`。
