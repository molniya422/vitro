# macOS Dock 设计与实现全细节拆解(Sonoma)

> 来源:用户提供的设计拆解(2026-10-24),作为 Vitro「macOS 对标」的定量规格,与 `nexus-dock-behavior-spec.md`(NeXuS 行为基线)、`effects-catalog.toml`(效果槽)并列。
> 机器可读参数映射见 `macos-parity.toml`;原型实现见 vitro-macos-parity。

---

## 一、底层渲染架构与材质实现细节
### 1. 进程与渲染基础
- Dock 是独立的系统级应用,路径为 `/System/Library/CoreServices/Dock.app`,用户登录时由 `launchd` 自动启动
- 渲染基于 Metal 图形框架,与 WindowServer 窗口服务协同,采用**离屏渲染+硬件合成**机制,保证基础 60fps、ProMotion 机型 120fps 全程流畅
- 所有视觉元素采用「矢量图形+PNG纹理」混合渲染,支持任意缩放无锯齿

### 2. Liquid Glass 液态玻璃材质参数(高级感核心)
Dock 的玻璃质感不是单纯模糊,而是 4 层结构叠加的物理级模拟:

| 层级 | 实现细节 | 浅色模式参数 | 深色模式参数 |
|------|----------|--------------|--------------|
| 背景模糊层 | 对桌面背景进行高斯模糊,同时提升饱和度避免发灰 | 模糊半径 20pt,饱和度+10% | 模糊半径 22pt,饱和度+8% |
| 基础填充层 | 半透明纯色填充,决定玻璃深浅 | 白色,透明度 18% | 黑色,透明度 25% |
| 颗粒纹理层 | 叠加单色噪点,模拟玻璃物理微结构,消除廉价塑料感 | 0.3% 透明度的均匀噪点 | 0.25% 透明度的均匀噪点 |
| 边缘光影层 | 内高光+内阴影,强化轻薄体积感 | 顶部 1px 内高光(白色30%透明度)底部 1px 内阴影(黑色10%透明度) | 顶部 1px 内高光(白色15%透明度)底部 1px 内阴影(黑色15%透明度) |

> 关键设计:**无外描边、无外投影**,完全靠材质本身区分层级,这是区别于廉价毛玻璃的核心。

### 3. 基础布局规范(底部Dock默认状态)
- 整体高度:随图标大小动态变化,默认 48pt 图标时,Dock 总高度约 68pt
- 内边距:左右内边距 16pt,上下内边距 10pt
- 图标间距:默认状态下水平间距 8pt
- 圆角规则:整体圆角半径 = Dock 总高度 / 2,两端为完整半圆,全程连续曲率无硬边
- 分隔系统:共 2 条 1pt 粗的半透明分隔线,透明度 20%
  - 左分隔线:**常驻应用区** ↔ **最近应用区**
  - 右分隔线:**最近应用区** ↔ **堆叠/系统功能区**

## 二、全动画系统:逐动画细节拆解

### 1. 悬停放大动画(Magnification)
- 触发:鼠标移入图标区域,且系统设置中开启「放大」
- 放大逻辑:以鼠标指针为中心,当前图标放大至最大值,向两侧图标依次递减倍率,平滑抛物线分布
- 参数范围:放大倍率 1.0x ~ 2.0x 可调,默认 1.2x;单图标最大不超过 128pt
- 时长:移入 0.2s,移出 0.25s
- 缓动曲线:苹果自定义 ease-out,接近 `cubic-bezier(0.25, 0.46, 0.45, 0.94)`,无弹性回弹,柔和克制
- 位移细节:底部 Dock 图标放大时同步向上偏移,偏移量 = 高度增量的 1/2,保证图标底部视觉对齐;侧边 Dock 则向屏幕外侧偏移
- 技术实现:基于 Core Animation 的 CABasicAnimation,对图标图层的 transform.scale 和 position 同时插值

### 2. 应用启动弹跳动画
- 触发:点击未运行的应用图标,应用启动过程中执行
- 动画序列:共 2 次完整弹跳 + 1 次小幅回落
  1. 第一次弹跳:向上位移 12pt,幅度最大
  2. 第二次弹跳:向上位移 6pt,幅度减半
  3. 回落至原位,结束
- 总时长:约 0.8s
- 缓动曲线:弹簧物理动画,阻尼系数 0.7,刚度系数 100,模拟真实物体弹跳的衰减感
- 同步状态:弹跳过程中,图标下方的运行指示器同步渐显
- 可配置:可在设置中完全关闭,关闭后启动时仅图标轻微高亮,无弹跳

### 3. 窗口最小化动画(3种模式)
#### (1)精灵效果(Genie,默认)
- 触发:点击窗口黄色最小化按钮 / Cmd+M 快捷键
- 视觉逻辑:窗口内容以纹理形式被「吸入」Dock 对应图标位置,窗口边缘沿贝塞尔曲线变形,上边缘先收缩、下边缘后跟进
- 技术实现:将窗口快照分割为 16×12 的网格顶点,每个顶点沿自定义路径独立运动,形成平滑曲面变形
- 时长:0.6s;缓动:ease-in-out
#### (2)缩放效果(Scale)
- 窗口整体等比例缩小,同时向 Dock 图标位置平移,最终消失在图标中心
- 时长:0.5s;缓动:ease-in
#### (3)吸入效果(Suck,隐藏模式)
- 终端开启:`defaults write com.apple.dock mineffect suck; killall Dock`
- 窗口从左下角开始快速收缩,像被吸尘器吸入,最终收束到图标
- 时长:0.4s,比前两种更利落干脆;缓动:强 ease-in

### 4. 窗口还原动画
- 最小化动画的**完全逆放**,变形路径、时长、缓动与最小化完全对称

### 5. Dock 显示/隐藏动画
- 触发:开启「自动显示和隐藏 Dock」后,鼠标移至屏幕边缘触发显示,移出 Dock 区域触发隐藏
- 延迟参数:显示延迟默认 0.3s(防误触);隐藏延迟默认 0.5s
- 动画时长:滑入/滑出 0.2s,沿垂直于屏幕边缘的方向平移;同步透明度渐变(0%→100%)
- 缓动:ease-out

### 6. 堆叠(Stack)展开动画
#### (1)扇形展开(Fan,默认,文件≤10个)
- 文件图标从堆叠位置沿扇形轨迹依次弹出,呈圆弧排列;每个图标延迟 0.03s 级联弹出,形成波浪感
- 排序:最上方为最新文件,底部为堆叠本体;总时长 0.3s
#### (2)网格展开(Grid,文件>10个)
- 图标从堆叠位置向四周扩散,形成 N 行 M 列网格,级联延迟 0.02s;附带文件名标签,悬停高亮
#### (3)列表展开(List)
- 右键选择「以列表显示」:垂直向下逐行展开,每行包含图标、名称、大小、修改日期
- 时长 0.25s,逐行渐入

### 7. 悬停标签(Tooltip)动画
- 触发:鼠标悬停图标 0.2s 后触发
- 出现:向上偏移 6pt + 淡入,时长 0.15s;消失:向下偏移 + 淡出,时长 0.1s
- 标签样式:毛玻璃材质,圆角 8pt;内边距水平 8pt、垂直 4pt;SF Pro Text 13pt 中等字重;与图标顶部间距 10pt

### 8. 拖拽重排与移除动画
- 重排:目标位置两侧图标自动平滑推开留出空位;松手后弹簧动画吸附到位,轻微回弹
- 移除:图标拖出 Dock 停留 0.5s 后出现「移除」提示;松手后图标向上飘起+渐隐+轻微缩放,时长 0.3s

## 三、图标系统:全状态规范与实现

### 1. 基础图标规范
- 形状:统一圆角正方形,圆角半径 = 图标边长 × 20%(SF Symbols 设计规范)
- 尺寸:默认 48pt(Retina 96px),可调范围 16pt ~ 128pt
- 渲染:应用图标 PNG 纹理,系统图标矢量图形

### 2. 全状态视觉细节
| 状态 | 视觉表现 | 附加元素 |
|------|----------|----------|
| 未运行 | 100% 正常亮度 | 无运行指示器 |
| 运行中 | 亮度不变 | 图标底部正下方直径 4pt 圆形指示器;浅色模式黑色40%透明度,深色模式白色60%透明度;与图标底部间距 6pt |
| 启动中 | 亮度提升 10% | 执行弹跳动画,运行指示器同步渐显 |
| 悬停 | 按设定倍率放大+位移,亮度提升 5% | 上方弹出名称标签 |
| 拖拽接收 | 放大 1.1x,图标半透明下沉 | 提示可接收拖拽的文件 |
| 未读通知 | 亮度正常 | 右上角红色角标:P3 系统红背景,1px 内高光;SF Pro Bold 12pt 白字;最小直径 16pt,位数增加自动加宽 |
| 禁用 | 饱和度降为 0,透明度 70% | 点击无响应 |

### 3. 特殊系统图标
- **启动台(Launchpad)**:固定在堆叠区左侧,银色金属质感火箭图标;点击触发「图标放大淡出→启动台网格淡入」转场
- **废纸篓(Trash)**:固定在 Dock 最末端,不可移除;空状态镂空,有文件塞满;拖拽文件至此时高亮
- **下载堆叠**:默认固定的文件夹堆叠,蓝色文件夹带向下箭头;接收的文件、隔空投送内容自动加入堆叠

### 4. 连续互通(Handoff)图标
- 位置:最末端、废纸篓左侧;样式与 iOS 端一致,左下角叠加小型设备标识
- 触发:同 Apple ID 设备在附近且开启接力,正在使用对应应用

## 四、功能模块:逐功能实现逻辑

### 1. 应用管理核心功能
- **应用启动与激活**:点击未运行图标 → launchd 启动;启动中图标持续弹跳,主窗口渲染完成后停止。点击已运行图标 → 激活应用,所有窗口前置
- **窗口切换与预览**:右键/Control+点击 → 菜单顶部显示该应用所有打开窗口的缩略图;点击缩略图切换;Force Touch 用力按压等效
- **退出与强制退出**:右键「退出」;按住 Option 右键 → 「强制退出」
- **常驻与移除**:右键→选项→保留在 Dock;拖出 Dock 删除快捷方式(不卸载);未常驻的应用退出后自动从 Dock 消失

### 2. 堆叠(Stack)功能
- 本质:Dock 中的文件夹快捷方式,任意文件夹拖入转为堆叠
- 显示模式:自动、扇形、网格、列表 4 种;排序:名称/添加日期/修改日期/创建日期/种类 5 种
- 交互:点击堆叠内文件直接用默认应用打开;拖拽文件到堆叠图标可直接移入

### 3. 最近使用应用
- 位置:左右分隔线之间的中间区域
- 规则:显示最近打开且未固定的应用,默认最多 3 个;系统设置可关闭

### 4. 最小化窗口管理
- 默认:最小化窗口以缩略图形式显示在 Dock 右侧,占用独立位置
- 「最小化为应用图标」模式:收入对应应用图标;右键图标可查看所有最小化窗口

### 5. 启动台集成
- 点击启动台:桌面内容淡出,所有应用以网格铺满屏幕;支持文件夹分组、全局搜索、多页翻页;点击空白/Esc 退出

## 五、系统设置与隐藏高级参数
- 公开可调:大小(16~128pt)、放大(开关+1.0~2.0x)、位置(底/左/右)、自动显示隐藏、弹跳开关、最小化效果(精灵/缩放)、显示最近应用、最小化为应用图标
- 终端隐藏参数(killall Dock 生效):
  - `defaults write com.apple.dock autohide-delay -float 0.1`(显示延迟)
  - `defaults write com.apple.dock autohide-time-modifier -float 0.5`(隐藏动画速度)
  - `defaults write com.apple.dock mineffect -string suck`(吸入效果)
  - `defaults write com.apple.dock show-recents-count -int 5`(最近应用数量)
  - `defaults write com.apple.dock persistent-apps -array-add '{"tile-type"="spacer-tile";}'`(空白占位符)

## 六、无障碍适配细节
- **减弱动态效果**:所有弹跳、变形、缩放动画变为简单淡入淡出,时长 0.2s
- **增强对比度**:Dock 背景不透明度提升至 80%,分隔线加粗,运行指示器更明显
- **系统缩放**:整体等比例放大
- **全键盘控制**:Tab 切换图标、回车打开、方向键移动选中项
