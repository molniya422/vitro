# 前端设计调研:MyDockFinder × BitDock(视觉体系 / 信息架构 / 动效 / 组件 / 主题系统)
> 2026-10-24 · 聚焦"怎么设计的",优缺点仅作设计成因注脚
> 证据源:官网、Steam 商店/指南/FAQ、腾讯云与 CSDN/博客园教程、微软商店页;macOS 基准见 macos-dock-spec.md

---

## 0. 一句话设计定位

- **MyDockFinder:材质还原派** —— 用 WinUI/Mica 的系统级材质 + D3D11 动画,把 Windows 桌面"变成" macOS;设计目标是"以假乱真"(用户实测可做到 100% 仿真)。
- **BitDock:组件装饰派** —— 用 50+ 功能图标 + 动图 + 特效开关,把 dock 做成"桌面控制中心";设计目标是"可玩性"。
- 光谱中间(原生质感 × 高可玩性 × 轻量)= Vitro 位置。

## 1. 视觉体系对比

| 维度 | MyDockFinder | BitDock | macOS 基准(我们已有) |
|---|---|---|---|
| 材质 | **WinUI 模糊 + Mica 云母**;全局实时动态模糊,强度可调 | 透明度 0-100% 微调;无 Mica 级材质描述 | 四层液态玻璃(模糊20/22pt+填充+噪点+内高光) |
| 模糊控制 | **两级体系**:全局模糊强度为默认,单项可勾选"自定义"覆盖(官方指南 2.x 节) | 单级透明度滑杆 | 系统固定 |
| 色彩 | 深浅色跟随系统;自定义配色方案 | 皮肤即配色;**定时换肤、昼夜自动切换** | 深浅双模式+壁纸取色(Sequenzo+) |
| 图标 | 工坊**图标包/主题包**(订阅→下载→应用);**图标遮罩**(全局遮罩+单图标右键遮罩,统一杂牌图标质感);大小可调 | **全格式:ICO/PNG/JPG/SVG/动静态 GIF/BMP**+alpha 透明;锁定防误拖 | 写实 48pt、圆角 20% 边长 |
| 排版 | 未公开细节 | 插件可调大小/颜色/字体 | SF Pro 13pt medium 标签 |
| 渲染 | **D3D11 硬件加速** | **Direct2D 硬件加速**(CSDN 性能文实证) | Metal/合成器 |

> 渲染选型注:两家都走 GPU 矢量/位图合成(D3D11/D2D),与 Vitro 的 D2D/DComp 决策一致——商业产品已验证该路线。

## 2. 布局与信息架构

### MyDockFinder(桌面级 IA:三件套接管)
```
屏幕左上:MyFinder 菜单栏(系统菜单 + 音量/网络/输入法/亮度控制) ← 替代任务栏系统区
屏幕右上:macOS 风格通知弹出(微信/QQ 消息)
屏幕底部:Dock(常驻图标 | 运行任务带窗口预览 | 文件夹图标[缩略图+二级目录])
全屏层:启动台
设置:偏好设置 = 主题 / 托盘 / 屏幕 / 窗口动画 / 全局(启动方式) + 预览(大小/延迟) + 最小化(三动画勾选)
```
- dock 文件夹是**迷你访达**:右键切缩略图/排序、左键展开二级目录、悬停显示全名、文件可拖出移动/复制。
- 窗口预览参数化:大小、延迟时间两个滑杆(偏好-预览)——我们把这两个参数做进了 macos-parity 原型,方向一致。

### BitDock(产品矩阵式 IA:自由拼装)
```
屏幕边缘:Dock(应用图标 | 功能图标[50+] | 托盘盒子) — 智能隐藏(边缘触发)
可选顶栏:BitBar(仿菜单栏)
全屏层:LaunchPad(应用网格,可建文件夹分组)
菜单形态:网格菜单 / 列表菜单(图标分类收纳)
桌面画布:BitDesk 小组件(时钟/天气/日历/系统状态/便签/媒体)— "搭积木"自由拖放
呼出层:Alt+空格 快速启动器
设置:Dock 设置→美化/外观(隐藏任务栏等);插件级:大小/颜色/字体
工作模式:辅助(不动任务栏)/ 高效(Dock+Bar 替代)/ 极简(仅 Dock)三档切换
```
- 两种插件摆放范式并存:**docklet(入 dock)** 与 **widget(桌面自由画布)**;NeXuS 逆向里 Shelf/桌面 Hotspot 同构。

## 3. 动效系统对比

| 动效 | MyDockFinder | BitDock |
|---|---|---|
| 悬停放大 | ✓ | ✓(仿 Mac) |
| 启动弹跳 | —(未强调) | **弹跳提示**(注意力效果,与 NeXuS/我们三方趋同) |
| 最小化 | **三种动画**(勾选切换;D3D11;"和 macOS 几乎一模一样",可调速) | 窗口动画(开关) |
| 拖放 | 拖入 dock 动画(管理员模式失效) | 图标飞入飞出 |
| 装饰特效 | — | **渐变闪烁**等,特效随心开关 |
| 速度控制 | 窗口动画调速 | 特效总开关 |

> 设计判断:MyDockFinder 的动效=少而真(每种都对标 macOS 参数);BitDock=多而炫(可玩性优先)。Vitro 双档案(macOS 克制/Vitro 弹性)+ 效果槽目录正好把两种口味都覆盖。

## 4. 组件级设计

| 组件 | MyDockFinder | BitDock |
|---|---|---|
| 运行指示 | 图标任务进度条(复制/下载/播放,跟随系统任务栏进度 API) | 运行状态动态指示 |
| 通知 | 右上 macOS 弹出 + 图标未读角标(IM 原创计数算法) | 通知徽标管理 |
| 窗口预览卡 | 悬停预览(含 UWP),大小/延迟可调,一键切换/关闭 | 悬停缩略图预览 |
| 文件夹/堆叠 | 缩略图 + 二级目录 + 拖出 | 网格/列表菜单 |
| docklet | 天气(图标=实时天气,预览=预报,允许不一致) | 50+ 功能图标(截图/取色/护眼/电源等工具化) |
| 托盘 | **托盘代理**(顶栏收编系统托盘,口碑三柱之一) | 托盘盒子收纳 |

## 5. 主题与个性化系统设计

- **MyDockFinder**:工坊订阅制(图标包/主题包先订阅后下载,软件内应用)+ 深浅色 + 自定义配色 + 配置文件手改(设置没有的选项直接改文件,社区有"四处配置段"教程)→ **深度用户逃生舱**设计。
- **BitDock**:皮肤站(BitSkin)+ 内置一键换肤 + **定时换肤/昼夜自动切换** + 插件级大小/颜色/字体微调 → **日常用户游乐场**设计。
- 设计启示:两级策略可并存——Vitro 主题 TOML 热重载(PLAN §4.5)即"配置文件逃生舱",再加昼夜感知换肤(电池感知的姊妹特性)即"游乐场"。

## 6. 各家设计 Top5 亮点(可直接抄进 Vitro)

**MyDockFinder**
1. 两级模糊控制(全局默认 + 单项覆盖)——设置 UI 范式
2. 图标遮罩统一杂牌图标——原生 D2D 用圆角裁剪+底板+遮罩实现,直接解决 §4.4 自带图标风格混杂
3. 进度条跟随系统任务栏进度 API——数据源现成
4. 托盘代理进顶栏——体验闭环关键件
5. 文件夹=迷你访达(缩略图/排序/二级目录/拖出)

**BitDock**
1. docklet 与 widget 双摆放范式(dock 内 + 桌面画布)
2. 三工作模式(辅助/高效/极简)一键切换——降低"全家桶"门槛
3. 定时换肤/昼夜自动切换
4. 动图+alpha 图标(视觉表达力上限高)
5. 快速启动器 Alt+空格(独立呼出层)

## 7. 设计短板(对方踩过的坑)
- MyDockFinder:接管 Explorer 导致动效与系统状态互相牵连(任务栏 alpha=0 卡死即设计耦合的代价);设置项多到社区要靠改配置文件
- BitDock:开机"先裸桌面再逐个加载"——**首帧体验设计缺失**(插件串行初始化,无骨架屏/统一入场);特效堆叠缺材质统一层,观感"堆料"

## 8. 对 Vitro 的设计规范输出(增量)
1. 设置面板采用 **MyDockFinder 式分区 + 两级覆盖**(全局材质默认,单项可覆盖)——补进 PLAN §4.5
2. 图标统一管线:提取图标 → squircle 裁剪 + 底板渐变 + 可选遮罩 → 入 dock(解决混插风格)
3. 启动序列设计:**统一入场动画**(图标交错淡入)替代逐个加载,冷启动 <400ms 内一次成型——直接打 BitDock 的首帧短板
4. 主题引擎补昼夜感知换肤(与电池感知并列)
5. docklet/widget 双范式:§4.3 已有 docklet;桌面画布型 widget 列为 M5+ 选项(与 Shelf 二选一或并存)
